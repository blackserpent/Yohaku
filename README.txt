YŪGEN — Art Archive

A responsive gallery website with a Japanese-inspired dark editorial aesthetic.

Open index.html in a browser or deploy the whole folder to GitHub Pages, Netlify, or Vercel.

Contents:
- index.html
- style.css
- script.js
- assets/ (75 artwork images)

Features: responsive grid, collection filters, animated gallery reveal, artwork lightbox, keyboard navigation, mobile layout.
